I never got to run the Minecraft server as a kid. Someone else's brother had the computer that stayed on. Someone else set the spawn.

I am building it now. Mods I actually want. Rules I can defend. A world that does not reset because a host got bored.

It is a small machine and a whitelist and the kind of problem I liked at twelve and can finish at this age. That is the point. Some hobbies are just delayed permissions.

When it is up, people I know can come in and build. Not a public chaos server. A place.
